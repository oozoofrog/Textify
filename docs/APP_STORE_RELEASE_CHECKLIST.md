# Textify App Store / TestFlight 릴리즈 체크리스트

- 작성일: 2026-03-13
- 대상: Textify iOS 앱 (Swift 6 / iOS 26)

---

## 1. 출시 기준

### TestFlight 베타 최소 기준
- 사진 1장을 선택해 ASCII 결과를 생성할 수 있다.
- `palette`, `output width`, `contrastBoost`, `invertBrightness` 옵션이 안정적으로 반영된다.
- 결과를 `복사`, `공유`, `저장` 중 하나 이상으로 소비할 수 있다.
- 최근 작업 히스토리를 다시 열 수 있다.
- 생성 실패, 저장 실패, 권한 거부 시 사용자 메시지가 명확하다.

### App Store 제출 최소 기준
- TestFlight 기준을 모두 만족한다.
- 저장 권한 `notDetermined / denied / restricted / authorized` 흐름이 모두 확인되었다.
- 설정 화면에서 개인정보/권한 안내와 피드백 경로를 확인할 수 있다.
- App Icon, 스크린샷, 메타데이터, 개인정보 답변 초안이 준비되었다.
- 대표 기기에서 portrait/landscape 수동 QA를 마쳤다.
