## 설명문 초안
Textify는 사진을 ASCII 문자열 패턴의 그림으로 바꿔주는 앱입니다.

사진을 고르면 기본 설정으로 바로 텍스트 아트를 만들고, 팔레트·출력 폭·대비·밝기 반전을 조정하면서 원하는 결과를 빠르게 찾을 수 있습니다.

### 주요 기능
- 사진을 ASCII/문자 패턴 그림으로 변환
- 다양한 문자 팔레트 제공
- 출력 폭, 대비, 밝기 반전 조정
- 원본 / ASCII / 비교 미리보기
- 결과 복사, 공유, 이미지 저장
- 최근 작업 히스토리 확인 및 삭제

### 이런 분께 추천해요
- 사진을 터미널 스타일의 텍스트 아트로 바꾸고 싶은 분
- SNS, 프로필, 커뮤니티에 개성 있는 ASCII 이미지를 올리고 싶은 분
- 팔레트별 문자 분위기를 빠르게 비교하고 싶은 분

### 개인정보 및 처리 방식
- 선택한 사진은 기기 안에서 처리됩니다.
- 사진은 사용자가 저장을 요청할 때만 사진 앱에 기록됩니다.
- 별도의 계정 생성 없이 바로 사용할 수 있습니다.

## 리뷰어 참고 사항 초안
- 이 앱은 OCR 앱이 아닙니다.
- 사용자는 PhotosPicker로 사진을 선택하고, 앱은 해당 이미지를 ASCII 문자열 패턴 그림으로 변환합니다.
- 저장 기능은 생성한 결과 이미지를 사진 보관함에 기록하며, 사진 저장 권한이 필요합니다.
